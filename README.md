# Digital Resume – Najet Zridette

Online resume built from scratch with **pure HTML and CSS** (no framework, no template), as part of the Epitech Web bootcamp (days 04-05).

🔗 **Live website:** https://YOUR-GITHUB-USERNAME.github.io/webd04/

## Features

- Responsive design (desktop, tablet and phone) using Flexbox and a media query
- Sticky navigation bar with smooth scrolling to each section
- Fade-in animation on the hero banner and hover transitions on links, buttons and skill tags
- Collapsible experiences built with the native `<details>` / `<summary>` elements
- Contact form that opens the visitor's e-mail app (no server needed)
- W3C-compliant HTML
